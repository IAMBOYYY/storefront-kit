Your config.json is ready!

Download and upload it to the root of your GitHub repo. Your store updates in ~30 seconds.

1
Upload config.json to your GitHub repo root (replace existing)
2
Settings → Pages → Source → GitHub Actions → Save (skip if using Vercel)
3
Run the template cleanup command from Step 2 if you haven't already, to remove the templates you're not using
4
Visit /admin.html → log in → add products with multi-image upload
5
Orders appear automatically in /admin.html → Orders as customers check out — orders.json is created for you, no setup needed
6
If you enabled card payments, customer data includes names/phone/addresses — use Vercel + a private repo (see VERCEL-SETUP.md), not public GitHub Pages
